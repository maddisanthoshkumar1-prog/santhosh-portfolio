# Santhosh Kumar — Cybersecurity Portfolio

A responsive personal portfolio built with React, Vite, and custom CSS.

## Run locally

Requirements: Node.js 20+ recommended.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

- Replace the LinkedIn URL with your actual profile URL.
- Add a real contact email in the contact section.
- Add your resume as `public/resume.pdf` and wire a download link if you want one.
- Add only certifications you have actually earned, with valid links.
- Keep projects marked `Built` only when they are implemented and tested. PromptTrap AI and CyberRisk Graph are currently labelled as planned concepts.
- Add screenshots or a live demo for DataSniff when available.
